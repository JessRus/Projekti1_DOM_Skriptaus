**Tekijä:** Jessica Rusila

## Projektisuunnitelma

### Projektin idea

Sovellus on to-do lista minne voi lisätä ja poistaa tehtöviä, sekä merkata tehtävät valmiiksi

### Suunnitellut toiminnot

Listaa vähintään kolme sovellukseesi suunniteltua toimintoa:

- Voi lisätä to-do tehtäviä
- Voi poistaa to-do tehtäviä
- Voi merkata tehtävät tehdyksi
